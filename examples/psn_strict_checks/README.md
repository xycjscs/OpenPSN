# 全严格节点响应检查（论文 Study IV 的符号与精确对照）

本目录的运算全部使用有理数或符号表达式，表中小数只作显示。它验证的是
扇区扩散闭包所依赖的算子与精确关系，不做空间或角度离散，因此不约束
生产网格的截断误差。对应论文 `paper/studyIV.tex` 的 "Symbolic and exact
checks" 一段。

## 二维节点与连续方向

- **异质矩形斜射线。** 从 `(0, 1/5)` 沿 `(3/5, 4/5)` 进入 2×2 材料网格，
  恰在 `(27/20, 2)` 到达上边界。跨越两个内部材料面，三段光学厚度严格为
  `2、2、7/12`。零入射时，响应为 `3−exp(−7/12)−exp(−31/12)−exp(−55/12)`。
- **精确拼接与反射。** 对同一条射线在两个方向增加非等距的人为空间界面，
  并给非零入射。粗、细分区的出口坐标、边界标签和全部指数项系数逐项相同。
  上边界镜面反射整条出射迹，反射后在 `(2, 17/15)` 出射。射线同时穿过两条
  内部材料线时按一次角点事件处理。
- **所有连续方向的符号验证。** 在均质矩形中取空间源 `cos(kₓx)cos(kᵧy)`。
  将解析角通量代入一阶输运和二阶偶宇称方程，残差化为恒等零。按正、负两侧
  分别把面角做镜面反射，四个边界的通量差恒等为零。以 `p=Ωₓ kₓ`、
  `q=Ωᵧ kᵧ` 作为符号自变量，验证覆盖所有方向。另精确验证角积分原函数
  `atan(K μ/Σ)/K` 及各向同性散射源的联立闭合。
- **分层平板的逐层平衡。** 光学厚度 `1、1`、平衡源 `1、2` 的两层真空平板
  给出界面标通量 `3[1−E₂(1)]/2`、界面净流 `−1/4+E₃(1)/2`，吸收加泄漏等于
  总源 `3`。插入人为界面或切分角带后，两个方向的响应与逐单元平衡逐项不变。

## C5G7 原截面七群本征值

按 `c5g7_materials_pure.yaml` 的十进制文本读取并直接转为有理数。对每种
单材料取四面反射矩形，设 `A=diag(Σₜ)−S`（`S` 按 `[目的群][源群]` 排列）、
`f` 为 `νΣ_f`。均匀裂变源形状 `1` 给出 `Aφ=χ`，故 `k∞=fᵀA⁻¹χ`。逐材料检验
七个群平衡恒等式与裂变本征方程。连续裂变响应是正算子且把常数 `1` 映成
`k∞·1`，其上确界算子范数即 `k∞`，该正本征值为主值。下表使用输入文件的
原始裂变谱。

| 四面反射单材料 | 原谱 `k∞` | 谱归一化后 `k∞` |
|---|---:|---:|
| UO₂ | 0.738214699120 | 0.738207924136 |
| MOX 4.3% | 0.839334157439 | 0.839326454428 |
| MOX 7% | 1.038903851962 | 1.038894317395 |
| MOX 8.7% | 1.147587627285 | 1.147577095270 |
| 裂变室 | 0.000279271184 | 0.000279268621 |

`c5g7_exact_results.json` 保存精确分数、本征通量与两种裂变谱的数值显示。

## 异质四分之一堆芯的严格上界

实际 `153×153` 几何使用材料编号 `0,1,2,3,4,6,7`，左、下反射，右、上真空。
对任意正群权 `w`，定义 `a_{m,g}=w_g Σ_{t,m,g}−Σ_h w_h Σ_{s,m,g→h}`。对非负
输运本征通量做加权全域粒子平衡，反射面净流为零，真空外流非负。若
`a_{m,g}≥λ νΣ_{f,m,g}` 且 `χ·w=1`，则吸收项至少为 `λ` 倍积分裂变产生项，
严格得到 `k_eff≤1/λ`。先用有理线性规划求权，再独立逐条用分数检验约束，
证书覆盖材料库全部 8 项与 56 个材料—能群约束：

```text
1037403747612234354480603702216339034783296539885707
---------------------------------------------------  < 947/500 = 1.894
 547813870751723379008637693543303455447860000000000
```

这是该材料集在真空与镜面反射边界下的严格单侧界，尚未给出四分之一堆芯的
精确值或 1 pcm 宽度的区间。

## 与 OpenMC 比较时的裂变谱输入

仓库输入 `Σχ=100000917761/100000000000=1.00000917761`，OpenPSN 的
`model.arrays` 与求解器按原谱读取；作为参考的 OpenMC 0.11.0 在读取 `chi`
后按出射组求和归一化。仅改变这一整体系数时，任意固定几何与散射模型下都有
`k_raw=(Σχ) k_normalized`，该等式也由上表五个精确七群对照验证。以约
`1.18722` 的归一化参考值计算，对应 `k` 差约 `1.0896 pcm`。这是输入归一化
的影响，不依赖节点细分，也不改变上界证书的性质。

## 复现

需要 Python 3.10 以上、`sympy` 与 `PyYAML`（`pip install -r requirements.txt`）。
14 项测试包括二维与七群的 10 项和分层平板 4 项，实测约 2 秒：

```bash
cd examples/psn_strict_checks
python3 -m unittest discover -s . -p 'test_*.py' -v
python3 generate_bound.py c5g7_materials_pure.yaml group_weight_certificate.json
python3 c5g7_exact.py c5g7_materials_pure.yaml --certificate group_weight_certificate.json
```
