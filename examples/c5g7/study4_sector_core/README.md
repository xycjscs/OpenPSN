# Study IV · C5G7 矩形四分之一堆芯的完整 5 × 6 SM 矩阵

扇区扩散闭包 `sector_diffusion` 在 `examples/c5g7/study2_rectangular/c5g7_rect_quarter_core.yaml`
上的完整扫表：`S=1,2,3,4,5` × `M=2,4,8,12,16,24`，共 30 个测点，逐点通过独立复扫。
输运算子与论文 `paper/studyIV.tex` 的 "C5G7 rectangular quarter core" 一段一致，
方法推导见 [`docs/psn4-sector-diffusion.md`](../../../docs/psn4-sector-diffusion.md)。

几何与材料沿用原输入：51×51 的 pin 布局、1.26 cm 节距、方形燃料中心与外围水层显式
建模，七群截面保持原样，左／下反射、右／上真空。每轴 `153·S` 个空间单元。
同几何 OpenMC 0.11 参考为 20,000 个活跃批次的 `k_generation` 均值
`k_ref = 1.187217554586068`，标准误 3.41 pcm；statepoint 的 `k_combined` 为
`1.187220349151050`，标准误 1.75 pcm。表中偏差为 `10⁵(k_eff − k_ref)`。

## 测点设置

- 极角用 TY3 三点规则，方位每扇区 `A+1 = 2` 个 Gauss 点（`A=1`），
  互余方位折叠开启。
- 60 线程上限，压缩因子池 + 共享极角 CHOLMOD 后端，`S=5` 的 `M=24` 点改用
  FP32 存储的压缩内核以容纳在内存预算内。
- 收录门：本征值相对变化 ≤ `1e-9`，独立复扫的相对源残差 ≤ `5e-9`，
  扇区扩散的线性相对残差门槛 `5e-12`。
- 部分测点从已有收敛源热启动，个别高阶点用粗网格的角度变化改善初始源；
  热启动只改变迭代路径，收敛解由独立复扫判定。`points.csv` 逐点记录
  冷/热启动、因子缓存与后端。
- `S=5` 的七群因子模板另行准备约 2144 秒；`M=16` 一列取自此前的同配置算例。
  带 `*` 的格子复用已存的分解因子。同机并行使墙钟只反映负载而非吞吐。
- 裂变谱按运行采用的原谱口径。OpenPSN 按输入读取，`Σχ = 1.00000917761`，
  而 OpenMC 0.11 读取后归一化，因此两者相差 `1.0896 pcm`。
  `points.csv` 附对该系数归一化后的代数折算偏差。

## 复现

求解单个测点（需要 `--opt sector-cholmod` 的构建，见
[`docs/psn4-sector-diffusion.md`](../../../docs/psn4-sector-diffusion.md)）：

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
python -m scripts.sector_diffusion_benchmark rect --sm 1,24 2,24 \
    --opt sector-cholmod --threads 60 --mem-limit-gb 43
```

由日志重建两张矩阵、色板图与论文表格（论文 `paper/tables/study4-core-*.tex`
即由此生成，逐格读回各次运行的本征值、残差与用时）：

```bash
python -m scripts.study4_core_report \
    --logs examples/c5g7/study4_sector_core/logs \
    --output examples/c5g7/study4_sector_core \
    --latex paper/tables \
    --fission-summary examples/c5g7/study4_sector_core/best_fission_summary.json
```

## 读法与边界

- 这是实测网格，不是收敛性证明。最佳格与 Monte Carlo 参考的差仍大于参考自身的
  3.41 pcm 标准误；矩形 MOX 组件在其最佳采样设置下保留数十 pcm 的偏置。
- 同几何、同 `S=1, M=24`、同 60 线程上限且都冷启动时，原版闭包为 `−10.12 pcm`
  / 128.08 s，扇区扩散为 `−54.09 pcm` / 340.68 s：最粗角分辨率下扇区闭包并不
  总是更好，两者在表中随加密交叉。
- 在 153×153 原网格上以 `M=4,8,16` 与 `M=8,16,32` 的相邻增量估计的局部方位收敛阶
  为 1.32 与 1.47，两个窗口外推到 `M→∞` 的偏差为 −54.64 与 −58.90 pcm（`I=8`、
  `A=1`）。固定 `M=16` 把 172×172 重划到 244×244 只改变 3.24 pcm。
