03What PSN actually does

Idea: solve transport with a diffusion solver

In each phase-space node (a square in space × a segment in direction) the angular flux is written as a P1 base function,

ψ(𝐫,Ω) = 1/4π [ φ(𝐫) − (1/3Σt) cosθ (n̂·∇)φ(𝐫) ] + C/4π

where φ satisfies the standard diffusion equation with k² = 3Σ²t. The node balance does not determine C — it comes from an angular integral over the node, which yields face-current and face-flux relations.

Closed-form node response — no quadrature

The face current and flux are integrated analytically over each face, with angular integrals in closed form (βi, αf, eqs 2.8a–d of the paper). The node map (J₄, q) → (Φ, φ̄, moments) is exactly linear in the 9 unknowns, so it is probed once per (material, polar line, azimuth) with nine basis vectors into a 9×9 matrix — the vectorised trick behind the 107× speedup of the reference implementation.

Global system: 15 × (M/2) small blocks

Interfacing all nodes gives a sparse system over face currents. With mirror boundaries the azimuth couples only m with M−1−m, so for I = 30 polar lines and M = 12 segments the problem is 15 polar lines × 6 mirror pairs = 90 independent blocks, each a dense system of size 2·(internal faces) + (boundary faces).

A(i, {m,m′}) u = b(q) → LU once, back-substitute every k-iteration

That is why this page can converge keff to 10⁻¹⁰ in a few seconds on a laptop, while the paper's 10404-node C5G7 case (7 energy groups, 17×17 pin assemblies) needs ~54 min on one core of the Python implementation.

Eigenvalue iteration

Standard power iteration with k-update and paraboloidal source moments (q₀, q₁ₓ, q₁ᵧ, q₂ₓ, q₂ᵧ per node, paper eq. 2.16 / App. B): the fission source keeps the full paraboloidal shape of the flux and is spectrally distributed by χ. Convergence criterion |Δkeff/keff| < 10⁻¹⁰.

keff = Fnew/Fold · kold

No ray effects by construction: directions are integrated continuously inside each polar segment instead of being discretised (the classical weakness of SN and MOC, Lathrop 1968).
